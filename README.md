# FMCG Demand Forecasting Ontology

## Overview

A knowledge engineering project that models demand forecasting factors in Sri Lanka's FMCG industry using Semantic Web technologies.

This ontology captures relationships between brands, macroeconomic indicators, seasonal events, market dynamics, and forecasting features to support AI-driven demand forecasting.

---

## Problem

Demand forecasting in the FMCG industry lacks a structured and machine-readable framework for representing market knowledge, economic influences, and seasonal demand drivers.

---

## Solution

Developed a 42-class OWL 2 ontology that models FMCG forecasting knowledge, including brands, provinces, economic indicators, seasonal events, and competitive standings.

---

## Technology Stack

- OWL 2
- RDF/XML
- Protégé
- Description Logic Reasoning
- Dublin Core Metadata

---

## Key Features

- 42 ontology classes
- Object and Data Properties
- Domain and Range Constraints
- Named Individual Instantiation
- Province-level Market Representation
- Competitive Brand Modelling
- Reasoning-enabled Knowledge Graph

---

## Applications

- Demand Forecasting
- Market Intelligence
- Knowledge Graph Construction
- Decision Support Systems
- AI and Machine Learning Integration
